Using UXCam with a Flutter Web app? You don't need the standalone Web SDK — the **Flutter UXCam SDK** records both mobile (iOS/Android) and Flutter Web sessions from the same plugin.

For setup steps, see the [Flutter Integration Guide](/docs/flutter).
