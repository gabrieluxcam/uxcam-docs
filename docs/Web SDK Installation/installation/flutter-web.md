# Flutter Web

Using UXCam with a Flutter Web app? You don't need the standalone Web SDK — the **Flutter UXCam SDK** records both mobile (iOS/Android) and Flutter Web sessions from the same plugin.

For setup steps, see the [Flutter Integration Guide](/docs/flutter).

## Flutter Web Limitations

Flutter Web sessions are video-based rather than DOM-based, so a subset of advanced features behaves differently or is not yet supported on the web platform.

For the full list of unsupported APIs, partial support, and recommended cross-platform patterns, see [Flutter Web Limitations](/docs/flutter-web-limitations).
