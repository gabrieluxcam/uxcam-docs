### Kotlin Multiplatform

### V. 1.0.0 (August 5, 2026)

- Initial release of the UXCam Kotlin Multiplatform (KMP) SDK, providing a shared Kotlin API for session recording across Android and iOS from a single codebase.
- Install via the Gradle plugin; add `uxcam-compose` for Jetpack Compose screen capture support.
- Bundles the native UXCam Android and iOS SDKs.
- Removed unsupported screen configuration APIs to ensure consistent behaviour across platforms.
